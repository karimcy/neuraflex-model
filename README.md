# NeuraFlex Flexibility Model

Interactive model of behind-the-meter flexibility (BESS + cooling) at grid-constrained UK data centres:
a 5-minute constraint-event simulation (power flows, battery state of charge, IT inlet temperature,
import ramp-rate compliance), site economics, growth model, and a fully referenced method (63 sources).

Live: https://karimcy.github.io/neuraflex-model/
Companion: [Neura Opportunity Map](https://karimcy.github.io/neuramap/)

Built by Neura Energy for the Innovate UK Consumer-Led Flexibility programme (competition 2509).
